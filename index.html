How to Use This App

Welcome to the Tempest Content Planner! Here's how to get started:

  • Add content by clicking on any time slot or using the Quick Add button
  • Navigate weeks using the arrow buttons or Today button
  • Edit content by clicking on any content item
  • View all content using the "View All" button
  • Print or export your content plan using the buttons in the header
  • Filter content by platform or content type using the filter dropdowns
  • Drag and drop content items to reschedule them

Only title, platform and content type are required fields.
